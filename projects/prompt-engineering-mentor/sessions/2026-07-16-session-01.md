## Principle learned

> A prompt's rules only bind if each one traces to a written rejection criterion — rules added for vibes ("be engaging, but professional, but creative") measurably dilute the rules that matter (see Module 04's before/after: deleting 5 vibe-rules improved compliance with the remaining 4).
